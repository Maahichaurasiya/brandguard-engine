## 📌 Core Features & End-to-End Workflow
1. **Multi-Format Content Input Layer:** Audits promotional copy, ad banners, and social collateral.
2. **Multi-Aspect AI Audit Engine:** Scans text for prohibited terms, missing disclaimers, unverified claims, and tone policy.
3. **Interactive Review Canvas & Feedback Board:** Displays flagged issues with severity tags, policy explanations, and actionable rewrites.
4. **Human Decision Portal:** Role-based approval pipeline (Creator → Manager → Compliance Officer) with custom audit logs.
5. **Governance Analytics Dashboard:** Reports compliance scores, violation trends, and guideline usage.

## 🛠️ Tech Stack & Implementation Details
- **Frontend & Dashboard UI:** Streamlit (Python 3.10+), Custom CSS Components
- **Rule Parser & Audit Engine:** Python Regular Expressions (Regex), JSON Guidelines Store
- **Data & Analytics:** Pandas Data Engine
